H3000 暗场晶圆检测设备

面向先进制程与高密度互连的暗场（Dark-field）光学成像平台，用于整片晶圆表面及近表面缺陷的高速、高灵敏度筛查， 支撑前道制程监控、来料检与出货检等场景下的颗粒、划痕、残留、图形异常等缺陷检出与分类。

一、产品定位与适用场景

H3000 系列定位为中到高灵敏度暗场晶圆检测系统，在保持较高吞吐的前提下，对亚微米级散射体与微弱划痕具备增强对比度。 典型应用包括：CMP 后清洗与研磨监控、薄膜沉积与刻蚀后表面残留、光刻胶与硬掩模缺陷、键合/封装前晶圆外观检、以及部分 MEMS / 功率器件晶圆的颗粒与裂纹筛查。

二、暗场检测原理（简述）

暗场成像通过遮挡或偏离镜面反射方向的直射光，仅采集由表面微结构、颗粒、划痕等引起的散射光。 与明场相比，暗场对微小凸起、薄膜起伏及亚波长缺陷往往具有更高信噪比，尤其适合弱对比、低反射背景下的缺陷凸显。

  • 多角度或多通道暗场照明，可抑制特定方向的眩光并增强缺陷类型可分性。
  • 与精密载物台、同步触发与高速相机链路配合，实现整片晶圆步进或连续扫描。
  • 结合标定与补偿算法，降低翘曲、厚度不均带来的伪影。

三、系统组成与数据流

3.1 硬件子系统

  • 光学与照明：高稳定激光或 LED 窄带光源、暗场照明模组、收光物镜与滤光组件。
  • 运动与对准：真空或边缘夹持载台、精密 XY（及可选 θ）轴、预对准与中心定位传感器。
  • 成像链路：高分辨率面阵或线阵探测器、低噪声读出、与扫描节拍锁相的触发单元。
  • 整机与环控：隔振基座、温湿度与洁净度受控腔体（视配置）、安全联锁与急停。

3.2 软件与算法

  • 扫描与拼接：视场规划、重叠区融合、几何畸变与照度均匀性校正。
  • 缺陷检测：自适应阈值、形态学与纹理特征、多尺度 blob / 线状缺陷提取。
  • 分类与溯源：基于规则与统计学习或深度学习的缺陷编码（如 DOI / size / contrast），支持 SPC 与批次对比。
  • 数据管理：配方（Recipe）、用户权限、审计追踪、与 MES / YMS 的接口（按项目启用）。

四、主要能力亮点

  • 高灵敏度暗场：针对纳米颗粒、浅划痕、薄膜雾度等弱信号缺陷优化光学与增益策略。
  • 全片覆盖：支持主流晶圆直径（如 200 mm / 300 mm，具体以出厂配置为准），边缘排除区可配方设定。
  • 吞吐与分辨率平衡：多档分辨率与扫描速度，可在工程验证与量产监控间切换。
  • 可重复性：温漂与光源功率监控、定期自标定流程，保障跨班次、跨批次数据可比。
  • 人机工程：一键加载配方、缺陷地图与 die 级回溯、报告导出（PDF / CSV 等）。

六、工艺流程中的位置

H3000 通常部署在关键工艺站之后或出货前终检工位，与明场检测、电性测试、良率分析等形成互补： 暗场擅长早期发现散射敏感型缺陷，降低后续报废与返工成本；与制程参数、机台事件关联后，可支撑根因分析与闭环控制。

七、安装、维护与安全

  • 安装条件：建议独立防震基础、稳定电源与接地、符合洁净等级的使用环境。
  • 维护：光源寿命与强度监测、光学窗口清洁、载台与真空耗材更换周期按维护手册执行。
  • 安全：互锁门、激光/强光警示、急停与权限分级；操作员需完成激光与机械安全培训。
